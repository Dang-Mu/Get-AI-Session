# $log-session - 세션 기록 저장

## 레벨 기준

| 레벨 | 기준 | 예시 |
|------|------|------|
| L1 | 단순 지시 - 삭제, 이름 변경, 1줄 수정, 파일 열기 | "강하늘 탭 없애요" |
| L2 | 명확한 작업 - 단일 파일 편집, 요구사항이 뚜렷한 다단계 작업 | "성장포인트 어미 변환" |
| L3 | 분석 + 편집 - 패턴 파악, 크로스파일 변경, 디버깅, 일관성 검토 | "12개 파일 전체 정중체 변환" |
| L4 | 설계 / 아키텍처 - 시스템 구조 결정, 스킬/도구 생성, 방향 설계 | "세션 로깅 스킬 설계" |

## STEP 1: 프로젝트 정보 수집

```bash
~/.codex/skills/log-session/scripts/get-session-info.sh
```

JSON 결과에서 다음 필드를 사용합니다:

| 필드 | 용도 |
|------|------|
| `project_name` | 세션 로그 본문의 "프로젝트" 항목 + 파일명 접두사 |
| `downloads_dir` | 탐지된 다운로드 폴더 경로 (참고용) |
| `sessions_dir` | 저장 위치 (`{다운로드}/codex-sessions`) |
| `session_id_short` | 파일명에 사용 (앞 8자리) |
| `transcript_path` | 컨텍스트 손실 시 읽어볼 Codex transcript 경로 |

## STEP 2: 세션 작업 분석

현재 대화를 처음부터 검토합니다. 컨텍스트가 압축/요약되어 초반 대화가 손실된 경우 STEP 1의 `transcript_path`를 읽어 보강합니다.

1. **작업 단위로 그룹핑** - 사용자 요청 하나 = 작업 하나
2. **각 작업에 L1~L4 부여** - 위 레벨 기준 적용
3. **작업 흐름 추출** - `L2 -> L3 -> L1 -> L4` 형태로 정리
4. **주요 결정 추출** - 방향, 표현, 방식이 확정된 순간들
5. **다음 세션 컨텍스트 추출** - 미완, 보류, 이어받을 상태

## STEP 3: MD 파일 생성

파일명: `{프로젝트명}-{YYYY-MM-DD}-{세션ID 앞 8자리}.md`

> 모든 프로젝트의 세션이 `codex-sessions` 한 폴더에 모이므로, 파일명 앞에 프로젝트명을 붙여 구분합니다.

아래 형식으로 작성합니다:

```markdown
# 세션 로그: {날짜}

**프로젝트**: {프로젝트명}
**세션 ID**: {세션 ID 앞 8자리}

---

## 작업 흐름

{L1 -> L2 -> L3 ...}

---

## 작업 목록

### {작업 제목} [{레벨}]
{한 줄 설명}

### {작업 제목} [{레벨}]
{한 줄 설명}

---

## 주요 결정

- {결정 내용}
- {결정 내용}

---

## 다음 세션 이어받기

- {현재 상태 / 미완 작업 / 보류 사항}
```

## STEP 4: 파일 저장

1. STEP 1의 `sessions_dir`(`{다운로드}/codex-sessions`)이 없으면 생성합니다:
   ```bash
   mkdir -p {sessions_dir}
   ```

2. `{sessions_dir}/{project_name}-{YYYY-MM-DD}-{session_id_short}.md`에 저장합니다.

3. 저장 완료 후 파일 경로와 작업 흐름을 한 줄로 요약합니다.

## 설치

리포를 클론한 디렉토리에서:

```bash
./install.sh codex
```

`~/.codex/skills/log-session/`에 `SKILL.md`, `agents/`, `scripts/`가 복사되고 실행 권한이 설정됩니다.
